# Ember docs / GitHub Pages root

This directory is the GitHub Pages source (free plan allows only the repo root
or `/docs`). `.nojekyll` is present so filenames beginning with `_` and raw
markdown are served untouched.

- `index.html` — the project site
- `audio-pop.md` — the audible-pop analysis
- `version.json` — realm-sigil stamp, generated by `../build-sigil.sh`
